## 一言でまとめると

ESRF-EBS（Extremely Brilliant Source: 低エミッタンス蓄積リングへ改造した第4世代光源）のID29は、マイクロ秒パルスX線で室温シリアル結晶構造解析を行う世界初の専用ビームラインである。線量率が桁違いに高い（GGy/s級）のに、同じ線量でも連続ビームより損傷が小さく見える。その理由が「パルス構造」なのか「線量率」なのかが論点で、発表者は「おそらく両方」としている。

## 背景

### ESRF-EBSの光源性能 [s5-6]

- ESRF-EBSは旧ESRFより輝度（brilliance: 単位面積・単位立体角・単位バンド幅あたりの光子数。光の「絞りやすさ」の指標）が約100倍。第3世代光源とXFEL（X線自由電子レーザー）の間を埋めるとされる。
- MXビームラインはいずれもサンプル位置でフラックス（flux: 毎秒の光子数）が増えた。ID23-2（マイクロフォーカス）の例:

| | 改造前 | 改造後 |
|---|---|---|
| Flux | 4×10^11 ph/s | 1.5×10^13 ph/s |
| ビームサイズ | 7×4 µm² | 1.5×3 µm² |
| Flux density | 約1.4×10^10 ph/s/µm² | 約3×10^12 ph/s/µm² |
| 線量率 | 約0.5 MGy/s | 約50 MGy/s |

（Gy = グレイ。吸収線量の単位。1 Gy = 物質1 kgあたり1 Jの吸収。）

### ID29の位置づけ [s7-10]

- 他のマイクロフォーカスBL（第3・第4世代）に比べ、flux densityが100〜1000倍。
- 10〜90 µsのパルスで届けるため、線量率はMXで前例のないGGy/s級。Garman & Weik, 2023（Curr Opin Struct Biol）の比較図で、ID29だけが線量率軸の右端（約10^2 MGy/s以上）に孤立している。
- ビームライン仕様 [s10]:

| 項目 | 値 |
|---|---|
| エネルギー | 10-20 keV + 35 keV |
| バンド幅 (ΔE/E) | 0.4% / 1% |
| Flux | 約2×10^15 ph/s |
| ビームサイズ | 4×2 µm² |
| Flux density | >10^14 ph/s/µm² |
| パルス長 | 10 / 20 / 30 / 90 µs |
| 繰り返し | 925 / 462.5 / 231.25 / 115.625 Hz |

- 多層膜モノクロメータ（multilayer monochromator: 薄膜を何層も重ねた分光素子。結晶より広いバンド幅を通せるので高フラックスになる）を使用。
- パルスは2種類のチョッパーで作る。Heat load chopper（熱負荷を下げつつ90 µsパルスを生成）とFast chopper（10/20/30 µs）。

### なぜ室温・シリアルか [s9]

- 極低温（cryo, 約100 K）構造は、機能に関わる複数コンフォメーションを隠す、基質や阻害剤の結合を妨げる、ことがある。室温（RT）構造は生理的に意味のある構造や、より自然に近い熱運動を示す。
- ただし室温では放射線損傷が速く進むため、「1結晶＝1回折像」で多数の結晶を集めるシリアル結晶構造解析（SX: serial crystallography）が有力な手段になる。
- ID29はfixed-target（固定標的）方式。結晶を載せたフォイルやSiチップを動かしながら、設定した間隔（X-ray spacing）でビームを当てていく [s11]。

## 研究の核心: 放射線損傷は本当に小さいのか

### 損傷の種類（用語）

- Specific damage（特異的損傷）: ジスルフィド結合の切断、金属中心の還元など、特定の化学結合・部位に出る損傷。
- Global damage（全体的損傷）: 結晶全体の秩序低下。回折強度の減衰として観測する。
- Half dose（半減線量）: 回折強度が初期値の半分になる線量。

### 1. 標準タンパク質ではジスルフィド切断なし [s12-13]

- Orlans et al., Commun Chem（SµXの最初の実証）: Thaumatin、Lysozyme、Proteinase Kでジスルフィド結合の切断は見られなかった。
- 計38構造のうち、解析した2 Lysozyme・3 Proteinase K・3 Thaumatinの構造で、2Fo-Fc、Fo-Fcいずれの電子密度マップにも切断の兆候なし。
- X-ray spacingを50 → 10 µmに狭めても、積分強度の損失はない。

### 2. 放射線感受性ターゲットで検証 [s14]

感度の高い系を使って、より厳しく見ている。

- ウマ心筋ミオグロビン（Mb）: 光還元でFe³⁺ → Fe²⁺になると、鉄に配位した水が離れる（metMb → 中間体 → deoxyMb）。Fo-Fc差分マップで水とFeの負の密度として検出できる。
- ウリカーゼ + 9-メチル尿酸（MUA）: 酸素存在下でC5(S)-ペルオキソ中間体（5-PMUA）が生成する。このペルオキシドのC5-Op1結合は、X線ラジオリシス（radiolysis: 放射線による化学結合の切断）に非常に弱い。

### 3. ID29 vs ID23-2（パルス vs 連続）[s15]

同じフォイル搬送で比較（ミオグロビンと5-PMUA）。

| | ID29 | ID23-2 |
|---|---|---|
| Flux | 最大2×10^15 ph/s | 約3×10^12 ph/s |
| 露光時間 | 90 µs | 5 ms |
| ビームサイズ | 4×2 µm² | 4×4 µm² |
| 線量率 | 約1 GGy/s | 約4 MGy/s |
| 照射方式 | パルススキャン（231.25 Hz） | 連続スキャン |

- ID23-2は低線量（22〜30 kGy）でも損傷の兆候が出る。ID29は93〜137 kGyでもFo-Fcの変化が小さく、高線量なのに損傷が少なく見える。
- 「ID29では何か違うことが実際に起きている」とまとめている。

### 4. 線量よりX-ray spacingが重要 [s16]

- Foil上のミオグロビンで、83 / 135 / 220 kGy × 20 / 10 / 5 µm間隔を比較（Fo(dataset) − Fo(oxidised)、3σ）。
- 間隔を狭めるほど結合水の負の密度が増える。線量の影響は間隔が狭いときに顕著。Feの負の密度はどの条件でも出ない。
- メモ: 近接照射点への損傷の波及（周囲に拡散した損傷や熱）が疑われるが、スライドでは断定していない。

### 5. Siチップではfoilと挙動が違う [s17]

- Feに負の密度が全線量・間隔に依存せず観測される。一方、結合水はほぼ動かない（foilとは逆）。
- 要因の候補: 結晶が開口部に捕捉される（loading）、周囲の液体が除去され脱水・加熱の影響が出る可能性。原因は未解明。

### 6. 全体的損傷の強度減衰曲線 [s18-19]

| 条件 | Half dose |
|---|---|
| ID23-2（連続, 約4 MGy/s） | 69 kGy |
| ID29, 231.25 Hz | 1.66 MGy |
| ID29, 925 Hz（パルス間隔 約1.1 ms） | 実効 680 kGy |

- ID29（231.25 Hz）はID23-2より約1桁（約24倍）半減線量が大きい。
- 繰り返しを925 Hzに上げる（パルス間隔 約4.3 ms → 約1.1 ms）と、半減線量は下がる。パルス1発あたりの線量率は同じなので、パルス間隔がパルス効果の切り分けに使える。
- メモ: 間隔が短いと損傷や熱が回復しきらないことが原因の候補だが、スライドには理由の記載はない。
- 結論は「両方（パルス構造と高線量率）が寄与しているらしい」。

## 結論（発表者）[s20]

1. 同じデータをID29とID23-2で取ると明確な差がある。ID29は高線量でも損傷が小さく見える（specificとglobalの両方）。
2. ID29では線量よりX-ray spacingが重要（specific damage）。
3. 高線量率とビームのパルス性の両方が効いているように見える。
4. 20×20 µm間隔 + 試料に応じた透過率（transmission）が最適に見える。

## 今後の実験 [s21]

- 加熱の実測とシミュレーション。赤外サーモカメラ（100%透過、5×5 µm間隔）では最大約3 ℃の上昇、30 µsパルスの水の熱シミュレーションでは最大約300 ℃までの上昇が示唆され、両者に開きがある（ここがまだ決着していない点）。
- ID29とID23-2で、通常の回転法の強度減衰実験を室温と極低温で実施。
- Pulse slicing: 10/20/30 µs・90 µs未満でパルス長を変え、全体的損傷を監視する。

## 補足スライド [s24-25]

- ミオグロビン結晶: 4 M Sodium Malonate pH 6.0、板状 約25×10×10 µm、ASUに単量体（152残基・Fe 1個）、溶媒含量35%。
- AcNiRの多形（polymorphism: 同じタンパク質で結晶格子の寸法が異なる複数の形）: Ebrahim et al., IUCrJ（Diamondでのfixed-target SSX）。線量の増加とともに格子定数の分布が変化し、5×5 µm間隔では特に変化が大きい。放射線で駆動される結晶多形の変化が見える。

## 時分割結晶構造解析との接点（メモ・要確認）

スライド自体は放射線損傷の話で、反応を追う時分割実験は扱っていない。ただ次の点は、時分割SXを設計する際の前提になる。

- ID29はマイクロ秒パルスなので、µs〜msの時間分解能の反応を追う基盤になりうる（スライド9「time-resolved serial crystallography at room temperature」）。
- 損傷でなく反応由来の構造変化を見分けるには、X-ray spacing・線量・パルス条件の最適化が必須。今回の知見（20×20 µm間隔、試料ごとの透過率調整）はそのまま使える。
- Siチップとfoilで損傷挙動が違うため、時分割の搬送方式の選択に影響する可能性がある。

## 未解決の論点

- パルス効果と線量率効果の分離（pulse slicingで検証予定）。
- 試料加熱の大きさ（実測3 ℃ vs シミュレーション約300 ℃）。
- Siチップで見える、Feの負の密度の原因。
- 論文化の状況（スライドからは不明。確認が必要）。
